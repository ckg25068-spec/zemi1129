#### ページ１　「英彦山」

- 英彦山は日本三大修験道の一つ　※修験道とは日本独自の宗教があり、山に入って厳しい修行をする。山そのものが修行の場、これを修験道と言います。
そのため元々は走る場所ではなく、修験者が登るため、物資を運ぶため、修行をするためのルートだったのです。
それがベースとなっていき現在の国道500号になっていったのです。

#### 近代で「走れる山」になる

- そしてここから戦後~高度経済成長期にかけて車の発展や山道が舗装・拡張され英彦山への観光道路が整備されていきました
その結果として長くてカーブの多いワインディングが誕生しました
- 実際でも山頂付近までカーブが連続する道路(いわゆる峠)になっています。

#### 走り屋の文化の発生（1980~2000年代）
この年代から走りのピーク、走り屋としての峠としての歴史が刻まれていきます
- まずこの英彦山の特徴として挙げられるのが
- カーブ・連続コーナーが多い
- 標高差が大きい
- 交通量がそこまで多くない区間が存在する→これにより車のみならずバイクも好んで集まる環境へと変化していったのです
